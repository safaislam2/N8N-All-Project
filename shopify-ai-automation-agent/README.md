# 🤖 Shopify AI Automation Agent

An AI-powered Shopify automation system built with **n8n, Google Gemini, Telegram, and Shopify**.

This AI Agent allows users to manage Shopify products and access order information using simple natural-language messages through Telegram.

## ✨ Features

- 🛍️ Get Shopify products
- 📦 Get Shopify orders
- ➕ Create new products
- ✏️ Update existing products
- 🗑️ Delete products
- 🧠 Understand natural-language user requests
- 🔐 Focus on data accuracy and safe actions
- 💬 Send clear responses through Telegram
- 📣 Generate Product Summary, Use Cases & Marketing Highlights for new products
