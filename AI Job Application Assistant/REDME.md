# 🤖 AI Job Application Assistant

An end-to-end automated workflow built with **n8n** that processes form submissions, transforms data using dynamic AI models, renders pixel-perfect HTML/CSS templates, converts them into single-page PDFs, and emails them directly to candidates while logging records in Google Sheets.

---

## 🌟 Key Features
- **Automated Workflow:** Seamless processing from form submission to email delivery.
- **Dynamic HTML/CSS Templating:** Custom JavaScript logic ensuring strict 1-page minimalist design standards with clean, small font formatting.
- **High-Performance PDF Generation:** Real-time HTML-to-PDF dynamic conversion via API.
- **Gmail & Sheets Integration:** Automatic delivery of personalized PDFs and real-time logging.

---

## 🛠️ Tech Stack
- **Automation Orchestration:** n8n
- **Data Transformation & Logic:** Custom JavaScript (Node.js)
- **Templating:** HTML5 / Modern CSS
- **APIs & Services:** HTML-to-PDF API, Gmail API, Google Workspace

---

## 🔄 Workflow Logic
1. **Trigger:** Form Submission received via Webhook / Form Node.
2. **AI Processing:** Content generation and formatting.
3. **JS Rendering:** Input data parsed into CSS-optimized HTML structure.
4. **PDF Conversion:** HTML rendered to a single-page corporate standard PDF.
5. **Delivery & Logging:** PDF emailed to user and record logged to Google Sheets.
