# 🤖 AI Voice & Chat Agent

An advanced AI Agent system that can communicate with users through **voice calls and text chat** with real-time intelligent responses.

This project combines Artificial Intelligence, Voice Technology, Large Language Models, and Knowledge Base systems to create a human-like digital assistant.

---

## 🚀 Project Overview

AI Voice & Chat Agent allows users to interact with an AI assistant in two ways:

🎙️ Voice Call  
💬 Text Chat  

Users can ask questions, request information, or communicate naturally. The AI processes the request and provides intelligent responses automatically.

The same AI brain handles both voice and text conversations.
