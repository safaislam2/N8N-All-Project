# AI-Powered Invoice Automation System

An AI-based invoice processing automation system built with n8n that extracts invoice data from PDF files, structures the information using AI, stores records automatically, and sends reports.

## Features

- 📩 Automatic invoice collection from Gmail
- 📄 PDF invoice text extraction
- 🤖 AI-powered invoice data analysis
- 🧾 Structured JSON output
- 📊 Automatic Google Sheets accounting record
- 📧 Automated invoice report email

## Extracted Data

- Company name
- Invoice number
- Invoice date
- Customer details
- Product/service details
- Quantity
- Price
- Tax
- Discount
- Total amount
- Payment information

## Tech Stack

- n8n
- AI Agent
- OCR
- LLM
- Structured Output Parser
- Google Sheets
- Gmail Automation

## Purpose

This project reduces manual invoice processing time and helps businesses automate accounting workflows with AI.
