# 🤖 AI Learning Roadmap Agent

This is an AI-powered agent that helps users understand **how to learn any skill or profession step-by-step** in a simple and clear way.

---

## 🚀 Features

- 🧠 User input-based response
- 📚 Provides step-by-step learning roadmap
- ✨ Simple & beginner-friendly explanations
- 🎯 Covers any profession (e.g., Programmer, Designer, Marketer)
- ⚡ Fast and clean output

---

## 🛠️ How It Works

1. User selects or inputs a profession
2. AI analyzes the input
3. Generates a clear roadmap:
   - What to learn first
   - Tools & skills needed
   - Practice steps
   - Career tips

---

## 📌 Example

**Input:** Programmer  

**Output:**
- Step 1: Learn basics (HTML, CSS, JS)
- Step 2: Choose a language (Python/JS)
- Step 3: Build projects
- Step 4: Learn Git & GitHub
- Step 5: Apply for jobs or freelancing
